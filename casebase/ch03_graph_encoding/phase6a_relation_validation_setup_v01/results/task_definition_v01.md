# Phase 6A：下一阶段任务定义 v0.1

状态：准备；未训练。`ready_for_phase6b=false`。

推荐主任务为**已知生成规则家族辨认**，但必须先确认至少两种明确不同的组织家族，以及单栋形状、建筑数量、场地尺度或数据源不会直接透露类型；不能确认就不直接开展该任务。标签须来自生成器实际规则调用及参数记录，不从模型预测、真实案例的八项指标或页面自动分类产生。连续组织参数恢复只保留为可选次任务，不同时展开多个目标。

输入采用同一Graph提取的三组：街区指标＋共同条件、建筑集合、关系图。三组共有Block15、面积/编码建筑数/坐标尺度；集合与图共有Node8及面积/高度/体量的相同归一化派生值和掩码；图另有既有邻接及Edge12。单栋形状、数量和高度等控制条件需要设计为可比较范围，才能讨论组织关系的增量意义，不能因图组获得更多基本属性而声称关系有效。预测已直接输入或可直接重构的量属于目标冲突，训练前必须剔除或换目标。

最终观察预先确定主指标下三组辨认规则家族的表现、错误家族混淆以及案例是否可解释；主指标、实际有意义的差异及训练规模留待接口和标签明确后在6B训练前确定。本阶段不预设样本数、准确率阈值、轮数或GPU需求，也不承诺图一定更优。

划分按场地及同源基础布局的参数变体分组，同一布局的小扰动不得跨训练/测试；明确分别检查未见场地和未见参数组合。普通闭集分类须保留各待分类家族的训练样本，不能简单把整个待分类家族排除后仍按闭集分类解释结果。如果只在生成样本训练，真实城市案例用于解释/迁移检查，不称为真实城市监督留出测试。Phase 6A开发池已查看，不可后续冒充未见人工评估集。

当前执行项目中未找到可复用生成器接口；盘点限于当前项目文件与代码/文档关键词，没有扫描硬盘、访问平台或自行重建simforms/flexurban。规则家族、可控间距/组团/围合/高度参数、场地输入、批量调用及轮廓/高度输出能力均为未知，而非已确认不存在。详见generator_interface_inventory.csv。

阻塞项：真实接口、可追溯标签及组织混淆的排除方案。请研究者提供生成器代码路径，或一份包含场地、规则家族、参数、建筑轮廓与高度的输入输出样例。下一步仅供选择：补充生成器接口，或另行制定小规模人工标注任务；不自动启动人工标注、自监督或训练。接口缺失不阻塞真实案例候选页面。
