# v0.3候选特征角色规则

本文件说明v0.3候选特征角色，不是经模型性能挑选的v1.0最终特征集。当前字段注册信息见同目录的`feature_registry_v03.tsv`。

## 角色

- `core_model`：默认模型输入候选，仅保留不直接暴露城市、来源和绝对投影位置的归一化位置、形状、强度与相对关系字段。
- `auxiliary_interpretation`：米制绝对量、图规模、原始角度及与归一化字段重复但便于解释的字段；默认不输入模型，可供尺度条件或消融复核。
- `quality_audit`：缺失掩码、几何检查、cell失败及三类弱边标记。只用于质量分层，不作为形态学习信号。
- `provenance_trace`：ID、城市、国家、SRID、源关系、绝对投影坐标和WKT。用于身份与来源追溯。

## 约束

1. 城市、国家、SRID、源关系、文件路径、绝对投影坐标和WKT不得进入`core_model`。
2. 原始值与归一化值并存时，默认只把归一化表达列为核心候选；绝对量保留为辅助解释。
3. 原始朝向角不与双角正余弦同时进入默认输入；正余弦为核心候选，角度为辅助字段。
4. 缺失保留为`null + mask + reason`，不填0；0仍是合法观测值。
5. 相关性只产生人工复核清单，不自动删除建筑学含义不同的字段。
6. 长距离、低共享边界和组合弱边字段只做质量审查，不删边、不降权。
7. 绝对高度、面积、距离和图规模当前保留为辅助字段；是否作为显式尺度条件属于具体模型的设计选择。

## 当前争议项

`avh_w`、`hcv`等总体高度统计虽然为比率或加权量，但仍可能受城市数据源影响；该候选版本列为核心字段并在逐城市缺失/范围审计中检查。`connection_axis_alignment_i/j`以角度表示但属于相对关系，该候选版本列为核心字段；后续可评估是否改成周期编码。
