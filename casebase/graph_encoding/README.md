# 街区Graph数据与编码

本目录包含正式v0.3.2街区图数据、字段规范、数据筛选及编码实现。图以建筑为节点，以形态tessellation单元共享线边界形成候选邻接，保存建筑、街区与关系属性。生成模型和训练实验位于独立项目。

## 数据规模

| 口径 | 数量 |
|---|---:|
| 母样本 | 219419 |
| 最终编码入口 | 213054 |
| 有效Graph | 213052 |
| 无有效建筑的排除项 | 2 |
| 城市 | 24 |
| 节点 | 7107740 |
| 边 | 16100006 |

入口数包含排除项，与Graph文件数不同。数据版本、相对路径及索引SHA见`dataset.json`，103项注册字段见`specs/feature_registry_v03.tsv`。

最终街区筛选排除H01—H05、S01/S03/S05及建筑数上尾p99.5（369及以上）；S02/S04保留标记，S06保存组合原因。建筑级排除限定为面状几何提取后无正面积或0.4m内缩后为空。单建筑街区仍是1节点、1cell、0边的合法图。

## 文件分布

| 位置 | 内容 |
|---|---|
| `dataset.json` | 正式数据身份、索引和相对路径 |
| `dataset_io.py` | 仅依赖Python标准库的按ID读取接口 |
| `core/` | 建筑特征、cell、关系属性、排除规则及v0.3.2组装 |
| `pipeline/` | 街区筛选、12份分组清单、数据库读取、分批构图和状态核对 |
| `specs/` | 规则、参数、字段角色及继承规范 |
| `results/dataset/` | 正式Graph和索引 |
| `results/metadata/` | 来源、冻结清单、历史索引、统计和研究样本来源 |
| `results/runs/` | 与正式数据分开的编码运行结果 |
| `tests/` | 离线接口及编码行为检查 |

正式图采用压缩JSON，保留原sample_id和part/城市/chunk分区。`results/`是本地数据资产，不纳入版本控制。

## 读取接口与坐标

`GraphDataset(descriptor_path).get(sample_id)`返回一份解压后的图记录。路径相对描述文件解析；首次读取仅缓存索引中的ID、状态和路径，案例内容按需加载。未知ID抛出KeyError，排除ID抛出ValueError，不回退数据库或自动构图。

索引状态列为`case_status`，`graph_path`相对`results/dataset/`。主要内容包括`graph`、`block_attributes`、`nodes`、`cells`、`edges`和`exclusions`。缺失值与缺失原因随记录保存。

不同城市的`metric_srid`可能不同，WKT属于各自米制投影，不能直接跨城市叠加。街区总体指标取自原匹配建筑集合，节点来自通过编码适用性检查的集合，两种对象数并不总相同。历史研究成员表也不是正式全库的训练划分。

## 编码行为

cell算法采用0.4m建筑内缩、0.5m边界采样和大于1e-6m的共享线边界判定。节点不发生移动、抖动或合并；关系边表示候选空间影响，不等同于建筑语义关系。

分批运行采用追加账本和原子快照。母清单、总清单、part清单及代码身份参与核对；数据库建筑数与冻结数量不一致时记为failed并停止该案例的图输出。failed或interrupted产生非零退出状态，已有图的恢复检查包含元数据和验证标记。

新编码运行位于`results/runs/<run_id>/`，与`results/dataset/`中的正式数据分离。历史快照是来源记录，不是活动运行目录。

轻量读取接口不依赖几何或机器学习环境。筛选及编码实现使用NumPy、SciPy、Shapely、pandas和PostgreSQL相关库，数据库连接配置来自仓库根的本地环境文件。
