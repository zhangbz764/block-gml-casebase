# 屋顶检索实验的实现组成

实验从同一套LOD2建筑派生单一高度体块G1及屋顶几何G2，以统一总体形态M1和屋顶增量M2比较街区案例检索。Luxembourg是开发案例，多城市部分沿用相同的几何定义和检索参数。

## 模块与内容

| 文件 | 主要内容 |
|---|---|
| `roof_geometry.py` | 三维屋面三角化、投影面积、三维面积、坡度和高程 |
| `block_metrics.py` | 建筑可用性、街区覆盖率、总体形态与屋顶指标 |
| `retrieval.py` | 中位数/IQR缩放、分组距离、候选池和稳定排序 |
| `evaluation.py` | Luxembourg正式查询及建筑级分布距离 |
| `database.py` | Luxembourg源数据接入和实验表 |
| `multicity_database.py` | 多城市表结构、坐标参考和数据接入 |
| `multicity_pipeline.py` | 城市分层、批次处理、质量条件与合并结果 |
| `global_query_selection.py` | 多城市查询情景与查询集合 |
| `visualization.py`、`multicity_visualization.py` | 街区几何、指标与检索结果展示 |

编号Notebook对应Luxembourg指标、正式评价、多城市候选、多城市诊断、全库查询及图件输出，各模块保存具体方法实现。输出数据位于`outputs/`。

## 几何与聚合

建筑底面和三维表面位于各城市米制CRS，Z以米表示。屋面以XY三角化计算投影面积和三维面积；坡度按三维屋面面积加权，平均高程按水平投影面积加权。地面高程取GroundSurface外环Z的中位数，G1高度为屋顶平均高程与地面高程之差。

建筑屋顶高差比为`(max_roof_z-min_roof_z)/(max_roof_z-ground_z)`，非正分母对应不可计算状态。缺少必要RoofSurface/GroundSurface、非正高度或无效底面的对象有明确原因码。

街区指标包含规模、形状、覆盖、建筑高度、粒度和布局。标准差采用总体口径`ddof=0`；轴向方向分布使用[0,180)的18档；最近邻距离按街区面积平方根归一化。屋顶指标为面积加权坡度、建筑屋顶高差比中位数和建筑平均坡度的总体标准差。

## 检索表示

总体形态候选指标经相关性检查形成M1列表。开发实现的相关性阈值为绝对Spearman系数0.90，缺失较多者优先移出，同缺失率时按声明顺序处理。最终指标列表保存在配置中。

各指标以候选表的中位数和IQR缩放，零IQR取1。组内距离为均方根距离，排序并列以`block_id`稳定打破。M1返回总体形态最近案例；屋顶增强路径在相同M1候选池内以总体形态和屋顶距离重新排序。正式配置为候选池50、Top-5、屋顶权重0.35。

## 数据与结果边界

Luxembourg实验表位于`exp_lod2_roof_lu`，包含建筑指标、街区指标、检索结果、正式查询和正式评价结果。多城市实验位于`exp_lod2_roof_multi`，源`block`、`lod1`、`lod2`和`summary`关系与实验写入分离。建筑/表面采用服务端游标分批接入，避免一次加载全部表面。
