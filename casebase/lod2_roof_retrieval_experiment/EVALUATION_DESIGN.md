# Luxembourg正式评价设计

正式评价比较同一查询在M1总体形态检索与M2屋顶增强检索中的Top-5结果，衡量屋顶特征接近程度及总体形态代价。Luxembourg属于开发城市，评价不包含专家或公众评分，也不将检索使用的组合距离直接解释为建筑设计质量。

## 查询集合

Luxembourg正式集合包含20个查询，与5个开发查询互斥。常规查询按屋顶平均坡度四分位分为4层，每层4例；另有平缓、陡坡、高落差和高离散度4个边界案例。

边界案例依据稳定的指标与block_id排序确定，常规案例使用固定种子20260908及分层偏移。每个查询保存角色、分层、身份和三项屋顶指标。该20例集合与后续多城市的50例情景查询属于不同实验范围。

## 固定检索配置

| 项目 | 定义 |
|---|---|
| M1 | 开发阶段确定的11项总体形态指标 |
| 屋顶增量 | 坡度、高差比及建筑间坡度离散度 |
| 缩放 | 中位数/IQR，参数与指标列表随配置保存 |
| 总体形态候选池 | 50 |
| 返回数量 | 每路径5例 |
| 屋顶权重 | 0.35 |
| 身份规则 | 排除查询自身，并列按block_id稳定排序 |

两条路径使用同一候选信息及固定配置，避免把数据来源或候选变化混入屋顶增量比较。

## 建筑级分布评价

`evaluation.py`按街区汇集可用建筑，计算以下独立指标：

- 建筑平均屋顶坡度分布的Wasserstein距离，单位为degree。
- 建筑屋顶高差比分布的Wasserstein距离，为无量纲。
- 平屋顶建筑比例的绝对差，平屋顶定义为平均坡度小于5°。
- M1总体形态距离的变化。

缺少查询或候选建筑分布属于不可计算状态，不以0代替。各指标按查询计算Top-5均值，再报告跨查询的均值、中位数及M2减M1配对变化，不合并成新的综合质量分数。

## 数据与结果位置

`02_luxembourg_formal_evaluation.ipynb`对应正式查询及评价。`outputs/`下的建筑/街区Parquet、开发查询和方法配置构成输入；`outputs/formal_luxembourg/`包含：

| 文件 | 内容 |
|---|---|
| `formal_queries.csv` | 固定查询身份与分层 |
| `formal_retrieval_results.csv` | 两条路径的候选排序与距离 |
| `formal_evaluation_results.csv` | 候选对应的建筑级分布评价 |
| `query_summary.csv` | 查询级Top-5均值 |
| `aggregate_summary.csv` | 汇总统计与配对变化 |

数据库中的`exp_lod2_roof_lu.formal_queries`和`formal_evaluation_results`保存相应实验记录，与来源表分离。20查询×两路径×5候选对应200条检索结果。

## 解释范围

几何分布距离能描述屋顶形态的接近程度，但不覆盖空间使用、历史文化、设计意图等完整参照价值。城市数据的建模细节、语义一致性、来源精度和查询分层都会影响结果。Luxembourg评价与多城市比较共同提供方法观察，不能把开发城市的结果当作跨城市泛化证明。
